## Getting Started

To get started, install the dependencies:

```bash
npm install
```

Run the development server by:

```bash
npm run dev
```

Open [http://localhost:3030](http://localhost:3030) with your browser to see the result.

The landing page is redirected to the Login page.

This project uses App Router and the "src" directory.
```
src
└───app
│   │   page.tsx
│   │   layout.tsx
│   │   ...
│   └───(auth)
│   │   └───login
│   │       │   page.tsx
│   └───(route)  
└───components
│   └───Auth
│   │   └───UI
│   │       │   page.tsx
...
```
